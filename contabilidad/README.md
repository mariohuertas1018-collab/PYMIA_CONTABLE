# Pymia — Subproyecto Contable

Módulo de desarrollo contable de Pymia Consultores.  
Herramienta principal: **Alegra** (nube, DIAN-compliant, Colombia).

---

## Estructura

```
contabilidad/
├── configuracion/     # Setup inicial de Alegra, plan de cuentas, parámetros
├── procesos/          # Flujos y procedimientos contables estándar
├── plantillas/        # Modelos de facturas, cotizaciones, recibos
├── clientes/          # Onboarding contable por cliente
├── reportes/          # Plantillas de informes financieros
└── dian/              # Cumplimiento DIAN: facturación electrónica, obligaciones
```
